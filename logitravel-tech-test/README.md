# Logitravel Tech Test

Small React application to manage a list of text items.

## 🚀 Tech Stack

- React (Vite)
- JavaScript
- CSS

## 📦 Features

- Display a list of items
- Add new items (no empty values allowed)
- Select an item
- Delete selected item
- Delete item with double click
- Undo last change

## ▶️ Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open in your browser:

```
http://localhost:5173/
```

## 🧠 Notes

- The implementation prioritizes simplicity and readability
- All logic is handled within a single component to keep the solution straightforward
- No external state management or libraries were used

## 💬 Approach

The goal was to keep the implementation clean and easy to understand, focusing on core functionality rather than overengineering.
